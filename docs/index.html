🎯 What Is This?

Advanced AI MCQ Automation Bot is a free, open-source Chrome Extension + Flask Backend built by MVK Solutions. It automatically detects Multiple Choice Questions on any webpage using DOM parsing, OCR, and pattern recognition, then uses GPT-4, Gemini Pro, or DeepSeek to answer them in under 2 seconds with 97%+ accuracy.

🌟 Key Features

🧠 Multi-AI Provider Support

GPT-4, Gemini Pro, DeepSeek, HuggingFace — with automatic fallback between providers on failure.

🔍 100+ CSS Selectors

Works on 1000+ platforms out of the box. Shadow DOM, iframes, and custom components supported.

📸 OCR Screenshot System

Tesseract.js client-side OCR extracts text from image-based questions. No server needed.

💻 Auto-Write Code

GPT-4 generates complete solutions for HackerRank, LeetCode & CodeChef in 15+ languages.

🛡️ Stealth Mode

Randomized delays, mouse simulation, and human-like behavior to minimize detection footprint.

🚀 Production-Ready

Docker + Kubernetes deployment, Prometheus + Grafana monitoring, CI/CD with GitHub Actions.

🚀 Quick Installation (2 Minutes)

Step 1 — Clone the repository

git clone https://github.com/kranthikiran885366/ai-mcq-automation-platform.git

Step 2 — Install backend

cd backend && python install_dependencies.py

Step 3 — Configure API keys

cp .env.example .env — then add your OpenAI or Gemini API key (Gemini is free)

Step 4 — Start the server

python run_server.py

Step 5 — Load Chrome extension

chrome://extensions → Developer Mode → Load Unpacked → Select project folder → Done!

❓ Frequently Asked Questions

Q: Is the AI MCQ automation bot free? Yes — 100% free and open-source under MIT License. You only pay for AI provider API calls. Google Gemini Pro has a generous free tier.
Q: Which AI provider gives the best MCQ accuracy? GPT-4 gives 97.3% accuracy. Gemini Pro gives 95.8% and is free. DeepSeek is the most cost-effective for high-volume use.
Q: Does it work on HackerRank and LeetCode? Yes. The Auto-Write Code feature uses GPT-4 to generate complete solutions in 15+ languages including Python, Java, C++, and JavaScript.
Q: Does it work on Google Forms? Yes. Google Forms is one of the most thoroughly tested platforms with dedicated CSS selectors and 100% detection rate.
Q: Will it be detected by proctoring software? Stealth mode uses randomized delays and mouse simulation. Safe Mode auto-disables in lockdown browsers like ProctorU and Respondus.
Q: Does it support image-based MCQs? Yes — Tesseract.js OCR runs entirely client-side to extract text from question images. No server required for screenshot-based questions.
