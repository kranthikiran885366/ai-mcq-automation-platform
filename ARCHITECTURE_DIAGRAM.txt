EVENT FLOW (Event System)
================================================================================

Orchestrator Events:
  ├─ sessionStarted(data)      → Conversation created
  ├─ screenshotSent(data)      → Image sent to WhatsApp
  ├─ answerReceived(data)      → Message from WhatsApp received
  ├─ answersApplied(data)      → Options clicked on page
  ├─ conversationCleared(data) → Data cleared
  └─ error(error)              → Error occurred

UI Dashboard Listeners:
  ├─ on('sessionStarted')      → Display "Session started"
  ├─ on('screenshotSent')      → Display "Screenshot sent ✓"
  ├─ on('answerReceived')      → Display "Answers received"
  ├─ on('answersApplied')      → Update stats, highlight answers
  └─ on('error')               → Display error message
